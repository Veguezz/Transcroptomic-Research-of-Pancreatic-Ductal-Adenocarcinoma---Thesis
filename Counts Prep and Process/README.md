## Description

The raw counts were processed by the bioconductor package DESeq2 in R software. "Responders" and "Not Responders" groups were defined to obtained the log2foldchange of each gene expression and its p-value. Various graphs were made to illustrate the results, such as volcano plots and heatmaps.

It should be noted that counts of each database (TCGA and PanCuRx) were processed separately.
